# Void Chronicle - 게임 디자인 문서 (GDD)

## 🎮 게임 개요

### 하이 컨셉
"무한한 어둠 속에서 길을 찾는 2D 로그라이크 액션 RPG"

### 장르
- 주 장르: 로그라이크 (Roguelike)
- 부 장르: 액션 RPG, 던전 크롤러

### 타겟 플랫폼
- 웹 브라우저 (데스크톱 + 모바일)
- PWA 지원 (Progressive Web App)

### 타겟 플레이어
- 로그라이크 팬
- 캐주얼 ~ 하드코어 게이머
- 플레이 시간: 10-30분/런

---

## 🌍 세계관 & 스토리

### 배경 스토리
세계는 "Void"라 불리는 어둠에 집어삼켜졌다. 플레이어는 마지막 생존자 중 하나로, 점점 깊어지는 어둠 속 던전을 탐험하며 진실을 밝혀야 한다.

### 핵심 테마
- **고립과 생존** - 혼자서 끝없는 어둠과 싸운다
- **진보와 회귀** - 죽어도 얻은 지식과 자원은 남는다
- **선택의 무게** - 매 순간 리스크와 보상을 저울질한다

## 🎯 코어 게임플레이

### 게임 루프
```
메인 메뉴
  ↓
캐릭터 선택 (언락 가능)
  ↓
던전 진입 (층 1)
  ↓
┌─────────────────────┐
│ 탐색 → 전투 → 보상 │ ← 층마다 반복
└─────────────────────┘
  ↓
보스 전투
  ↓
승리 → 다음 던전 / 사망 → 메타 진행 → 재시작
```

### 핵심 메커니즘

#### 1. 던전 탐험
- **랜덤 생성 던전**: 매번 다른 레이아웃
- **안개 전쟁 (Fog of War)**: 탐험하지 않은 영역은 어둠
- **비밀 방**: 숨겨진 보물과 위험

#### 2. 전투 시스템 (실시간 액션)
- **기본 공격**: 클릭/탭으로 공격
- **스킬 시스템**: 4개 스킬 슬롯
  - 쿨다운 기반
  - 마나/에너지 소모
- **회피 메커니즘**: 대시 (스태미나 소모)
- **적 패턴**: 각 적마다 고유한 공격 패턴

#### 3. 캐릭터 성장

**런 중 성장 (휘발성)**
- 레벨업: HP/공격력 증가
- 스킬 획득: 런 중 랜덤 스킬 드랍
- 장비: 무기, 방어구, 악세서리

**메타 프로그레션 (영구)**
- **소울 (Soul)**: 사망 시 획득하는 화폐
- **영구 업그레이드**:
  - HP +5% (반복 구매 가능, 최대 10회)
  - 시작 골드 +100
  - 크리티컬 확률 +1%
- **캐릭터 언락**: 다양한 플레이 스타일
- **스킬 책**: 새로운 스킬 언락

#### 4. 아이템 시스템

**무기 종류**
- 검 (Sword): 균형잡힌 공격력/속도
- 단검 (Dagger): 빠른 공격, 낮은 데미지
- 둔기 (Mace): 느린 공격, 높은 데미지
- 지팡이 (Staff): 마법 데미지, 스킬 쿨다운 감소

**아이템 등급**
- Common (흰색)
- Rare (파란색)
- Epic (보라색)
- Legendary (금색)

**소모품**
- 체력 포션: HP 50% 회복
- 마나 포션: 마나 전체 회복
- 폭탄: 광역 데미지
- 텔레포트 스크롤: 랜덤 방으로 이동

## 🗺️ 던전 구조

### 층 구성
- **1-5층**: 튜토리얼 영역 (쉬운 적)
- **6-10층**: 일반 영역 (중간 난이도)
- **11-15층**: 어려운 영역
- **16-20층**: 엔드게임
- **보스층**: 5층마다 보스 등장

### 방 타입
1. **일반 방**: 적 2-4마리
2. **보물 방**: 아이템/골드
3. **상점**: 골드로 아이템 구매
4. **이벤트 방**: 랜덤 이벤트 (선택지)
5. **보스 방**: 층 보스 전투
6. **휴식 방**: HP 회복 (한 번만)

## 👥 캐릭터 (플레이어블)

### 1. 기사 (Knight) - 기본 캐릭터
- **스타일**: 근접 전투, 방어력 높음
- **시작 스킬**:
  - Shield Bash (방패 돌진)
  - Heal (체력 회복)
- **특성**: HP +20%

### 2. 도적 (Rogue) - 언락 조건: 100 소울
- **스타일**: 빠른 공격, 회피 중심
- **시작 스킬**:
  - Shadow Step (순간이동)
  - Poison Dagger (독 데미지)
- **특성**: 크리티컬 확률 +10%

### 3. 마법사 (Mage) - 언락 조건: 200 소울
- **스타일**: 원거리 마법, 높은 데미지
- **시작 스킬**:
  - Fireball (화염구)
  - Ice Nova (얼음 폭발)
- **특성**: 마나 +50%, HP -20%

### 4. 사냥꾼 (Hunter) - 언락 조건: 보스 3회 처치
- **스타일**: 원거리 물리, 덫 설치
- **시작 스킬**:
  - Arrow Shot (화살 공격)
  - Bear Trap (덫)
- **특성**: 이동 속도 +15%

## 👾 적 디자인

### 일반 적 (1-5층)
- **슬라임 (Slime)**: 느린 이동, 접촉 데미지
- **박쥐 (Bat)**: 빠른 이동, 낮은 HP
- **좀비 (Zombie)**: 중간 속도, 중간 HP

### 중급 적 (6-10층)
- **해골 전사 (Skeleton Warrior)**: 근접 공격
- **마법사 (Dark Mage)**: 원거리 마법
- **거미 (Spider)**: 독 공격, 웹 생성

### 상급 적 (11-15층)
- **미노타우르스 (Minotaur)**: 돌진 공격
- **유령 (Ghost)**: 벽 통과, 높은 데미지
- **악마 (Demon)**: 다양한 공격 패턴

### 보스
- **층 5**: 슬라임 킹 (Slime King)
- **층 10**: 네크로맨서 (Necromancer)
- **층 15**: 드래곤 (Dragon)
- **층 20**: 보이드 로드 (Void Lord)
