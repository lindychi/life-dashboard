## 주요 검증 항목

### 1. 세션 격리
- 각 세션의 메시지가 완전히 격리됨
- 세션별 컨텍스트가 독립적으로 유지됨
- 세션별 읽음 상태가 독립적으로 관리됨

### 2. 동시성 처리
- 여러 세션이 동시에 활성화되어도 정상 작동
- 세션 간 데이터 간섭 없음
- 참여자별 읽음 상태가 정확히 추적됨

### 3. 데이터 정합성
- 메시지가 시간순으로 정확히 저장되고 조회됨
- 읽음 상태가 메시지 추가/읽음 처리 시 정확히 업데이트됨
- 캐스케이드 삭제가 정상적으로 작동 (세션 → 메시지 → 읽음 상태)

### 4. 스레드 지원
- 부모-자식 메시지 관계가 정확히 유지됨
- 재귀 트리 조회가 정상 작동
- 스레드 루트 메시지와 답장 필터링이 정확함

### 5. 에러 처리
- 유효하지 않은 입력에 대해 명확한 에러 메시지 제공
- 존재하지 않는 리소스 조회 시 null 반환
- 권한 검증 (참여자만 메시지 전송, 읽음 상태 업데이트 가능)
