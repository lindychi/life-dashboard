# 히스토리 데이터 패턴 분석 가이드

Life Dashboard의 에이전트 히스토리 데이터를 분석하여 성능 인사이트를 도출하는 시스템입니다.

## 📊 분석 항목

### 1. 에이전트별 성과 분석
- **완료율**: 각 에이전트가 할당받은 태스크 중 성공적으로 완료한 비율
- **실패율**: 실패한 태스크의 비율
- **평균 소요 시간**: 태스크 시작부터 완료까지의 평균 시간
- **중앙값 소요 시간**: 이상치를 제거한 대표값

**활용 예시:**
- 완료율 50% 미만 에이전트는 설정 최적화 필요
- 실패율 30% 초과 에이전트는 에러 로그 정밀 분석 필요

---

### 2. 태스크 유형별 분석
- **성공률**: 각 태스크 유형(type)별 성공/실패 비율
- **평균/중앙값 실행 시간**: 태스크 유형별 소요 시간
- **주 담당 에이전트**: 해당 태스크를 가장 많이 처리한 에이전트

**활용 예시:**
- 성공률 60% 미만 태스크 유형은 실행 로직 점검 필요
- 평균 소요 시간 30분 초과 시 타임아웃 설정 증가 고려

---

### 3. 시간대별 패턴 분석
- **시간대(0-23시) 및 요일(일-토)별 태스크 발생 빈도**
- **시간대별 완료율 추이**

**활용 예시:**
- 특정 시간대에 완료율이 낮다면 시스템 부하 점검
- 주말/평일 패턴 파악 후 리소스 할당 최적화

---

### 4. 실패 패턴 분석
- **에러 키워드 추출**: `retry_errors` 필드에서 주요 에러 키워드 추출
- **빈도 순 정렬**: 가장 많이 발생한 에러부터 우선 해결
- **영향받은 에이전트**: 해당 에러를 겪은 에이전트 목록
- **샘플 에러 메시지**: 실제 에러 내용 3개까지 표시

**활용 예시:**
- 가장 빈번한 에러를 우선 해결하여 전체 안정성 향상
- 특정 에이전트에만 발생하는 에러는 해당 에이전트 설정 점검

---

### 5. 종합 권장사항
분석 결과를 바탕으로 자동 생성되는 개선 제안:

- ⚠️ **완료율 50% 미만 에이전트**: 태스크 할당 전략 재검토
- 🔴 **실패율 30% 초과 에이전트**: 에러 로그 분석
- ⚠️ **성공률 60% 미만 태스크 유형**: 실행 로직 점검
- ⏱️ **평균 소요 시간 30분 초과 태스크**: 타임아웃 설정 증가 또는 태스크 분할
- 🔍 **가장 빈번한 에러**: 우선 해결 대상
- ⏸️ **24시간 이상 방치된 미완료 태스크**: 모니터링 강화
- 📊 **전체 실패율 20% 초과**: 시스템 전반 안정성 점검 필요
- ✅ **전체 완료율 85% 이상**: 현재 운영 방식 유지

## 📈 분석 로직

### 데이터 소스
1. **agent_history 테이블**:
   - `type IN ('task_started', 'task_completed', 'task_failed')`
   - `request_group_id` 기준으로 태스크 그룹화
   - 시작 시각 ~ 완료 시각 계산

2. **task_queue 테이블**:
   - `type` (태스크 유형)
   - `status`, `retry_errors`, `started_at`, `completed_at`
   - `assigned_agent`

### 통계 기법
- **완료율** = (completed / (completed + failed)) * 100
- **평균 소요 시간** = AVG(completed_at - started_at)
- **중앙값 소요 시간** = PERCENTILE_CONT(0.5) (이상치 제거)
- **에러 키워드 추출** = Regex `([A-Z][a-zA-Z]+Error|timeout|failed|...)`

### 권장사항 휴리스틱
- 완료율 < 50% → 경고
- 실패율 > 30% → 긴급
- 성공률 < 60% (태스크 유형) → 점검 필요
- 평균 소요 > 30분 → 타임아웃 증가 고려
- 미완료 태스크 방치 > 24시간 → 모니터링 강화

## 💡 Tips

1. **분석 기간 설정**:
   - 너무 짧으면(< 7일) 통계적 신뢰도 낮음
   - 너무 길면(> 90일) 최근 변화 반영 어려움
   - **권장: 30일** (월간 리뷰용)

2. **최소 태스크 수**:
   - 기본값: 3개 이상 (통계적 유의성)
   - 신규 에이전트는 샘플 수집 후 평가

3. **실패 패턴 활용**:
   - 에러 키워드 기반으로 근본 원인 추적
   - 샘플 에러 메시지에서 공통 패턴 발견

4. **권장사항 우선순위**:
   - 🔴 긴급: 실패율 30% 초과
   - ⚠️ 경고: 완료율 50% 미만
   - ℹ️ 정보: 일반 개선 사항
