# 📊 LifeDashboard

> 사업/프로젝트/재정 전체를 한눈에 조감하는 개인 대시보드

## 🎯 목적

- 여러 사이드 프로젝트 상태 추적
- KPI 모니터링 (유저 수, 매출 등)
- 재정/FIRE 진행률 트래킹
- 목표/OKR 관리

## 📋 추적 대상 프로젝트

1. **MumMum** - 영어 학습 앱
2. **Rezoom** - 이력서 서비스
3. **정화의 영역** - 게임 (Godot)
4. **안부** - 앱 예정
5. **크레딧컨설팅** - 재정/FIRE

## 🛠 기술 스택

- **Framework**: Next.js 16
- **Styling**: Tailwind CSS 4
- **Database**: Supabase (예정)
- **Deployment**: Railway
- **Mobile**: PWA

## 🚀 MVP 기능

- [ ] 프로젝트별 상태/진행률 카드
- [ ] KPI 대시보드
- [ ] 재정 트래커
- [ ] 목표/OKR 트래킹
- [ ] 모바일 반응형 (PWA)

## 📦 설치 및 실행

```bash
pnpm install

```
